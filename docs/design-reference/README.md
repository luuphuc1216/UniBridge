# Design reference (CHỈ ĐỂ THAM KHẢO PHONG CÁCH)

Hai file lumora.md và baseline.md mô tả landing page bằng HTML/CSS/JS thuần.
Khi áp dụng cho UniBridge phải chuyển sang Next.js + Tailwind + shadcn/ui. Không copy cú pháp, không import, không dùng lại ảnh, URL, nội dung hay tên thương hiệu của chúng.

## Chỉ tham khảo các phần sau
- lumora.md: Services (danh sách đánh số, hover đổi nền, mũi tên trong badge tròn), Stats (khối số liệu nền tối), Footer, PillButton, Eyebrow.
- baseline.md: Programs (hàng đánh số), Stats (4 cột trên nền navy), Testimonials (3 card), Footer, pill button + arrow button, cách xen kẽ section sáng/tối bo góc lớn.

## BỎ QUA hoàn toàn
Loader intro, Lenis/smooth scroll, root font-size theo vw (adaptive rem), canvas liquid reveal, parallax, watermark chữ khổng lồ, nền đen #0a0a0a, màu cam #b15f2c, font/màu của file mẫu.

## Màu và font
Dùng bảng màu và font trong docs/UI_REDESIGN.md, không dùng của file mẫu.
